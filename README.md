# chuchulucos.shop

Sitio de presentación para las apps de Chuchulucos.

## Estructura

- `index.html`: página principal.
- `style.css`: estilos (modo claro y oscuro).

## Apps previstas

1. Generador de códigos QR, con direcciones cortas.
2. Pseudocódigo.
3. Programación en C.

## Publicar en HostGator

Sitio estático: subir `index.html` y `style.css` a `public_html/` por cPanel o FTP.

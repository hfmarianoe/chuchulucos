# Reglas de Karpathy

Cuatro pautas de comportamiento para reducir errores comunes de los LLM al programar, derivadas de las observaciones de Andrej Karpathy. Origen: [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills) (antes de forrestchang).

1. **Pensar antes de programar:** declarar supuestos, presentar alternativas, preguntar si algo no está claro.
2. **Simplicidad primero:** el mínimo código que resuelve el problema, nada especulativo.
3. **Cambios quirúrgicos:** tocar solo lo necesario y limpiar solo lo propio.
4. **Ejecución guiada por metas:** definir criterios de éxito verificables y repetir hasta cumplirlos.

## Instalación

Como skill `karpathy-guidelines` en `.claude/skills/karpathy-guidelines/`. Es solo Markdown (sin scripts). Se aplica en el chat (nube) y en local con `git pull`. No se añadió al `CLAUDE.md` del repo, para no mezclarlo con las reglas de proveedores.

Si las quieres siempre activas, copia el texto de la skill a `CLAUDE.md`.

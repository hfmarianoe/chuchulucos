# react-best-practices (Vercel)

Skill con 70 reglas de rendimiento para React y Next.js, mantenida por Vercel Engineering. Origen: [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills), carpeta `skills/react-best-practices` (MIT). Equivale a `npx skills add vercel-labs/agent-skills@react-best-practices -g -y`.

## Instalación

Copiada tal cual (solo Markdown, sin scripts) a `.claude/skills/react-best-practices/` y a `~/.claude/skills/` de esta sesión, como en la captura con `-g`. En el chat (nube) y en local con `git pull` se carga desde el repo. Para tenerla global en tu equipo: `npx skills add vercel-labs/agent-skills@react-best-practices -g -y`.

## Nota

Este sitio es HTML estático, sin React, así que por ahora no se activará. Útil cuando agregues apps en React o Next.js.

## Quitar

Borra `.claude/skills/react-best-practices/`.
